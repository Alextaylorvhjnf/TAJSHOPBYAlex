# 👑 تاج الکترونیکس — TAJ Electronics

فروشگاه اینترنتی **Full-Stack و Production-Ready** کالای دیجیتال — با پنل مدیریت کامل، دستیار خرید هوشمند (AI)، درگاه پرداخت زرین‌پال، پرداخت کارت به کارت با تأیید رسید، سیستم تخفیف، نظرات، مقایسه محصولات و SEO.

> این پروژه یک Demo یا Template نیست؛ تمام عملیات‌ها (احراز هویت، سبد خرید، سفارش، پرداخت، مدیریت) واقعی و متصل به دیتابیس هستند.

## 🧱 تکنولوژی

| لایه | تکنولوژی |
|---|---|
| فریم‌ورک | **Next.js 16 (App Router)** + TypeScript 5 |
| UI | Tailwind CSS 4 + shadcn/ui (New York) + Framer Motion + Lucide |
| دیتابیس | Prisma ORM (SQLite — قابل تغییر به PostgreSQL) |
| احراز هویت | Session-based (bcryptjs + httpOnly cookies + RBAC) |
| اعتبارسنجی | Zod (سراسری) |
| State | TanStack Query + Zustand |
| AI | z-ai-web-dev-sdk (داخلی) **یا** Gemini API (کلید از پنل مدیریت) با Tool Calling |
| پرداخت | زرین‌پال v4 + کارت به کارت با رسید |
| آپلود | sharp (تبدیل خودکار WebP + اعتبارسنجی magic-bytes) |

### پنل مدیریت (/admin)
- داشبورد با نمودار فروش ۳۰ روزه + Pie وضعیت سفارش‌ها + کارت‌های آماری

- مدیریت سفارش‌ها (تغییر وضعیت + کد رهگیری)، کاربران (Block/Role)، پرداخت‌ها (تراکنش‌های درگاه + رسیدهای C2C با تأیید/رد)
- مدیریت نظرات (تأیید/رد/حذف) + Audit Log کامل عملیات ادمین‌ها
- تنظیمات: فروشگاه، درگاه‌ها (زرین‌پال + کارت به کارت با «تست اتصال»)، هوش مصنوعی (کلید Gemini/مدل/Temperature/System Prompt/تست اتصال)
- RBAC: `SUPER_ADMIN`, `ADMIN`, `SUPPORT`, `PRODUCT_MANAGER`, `ORDER_MANAGER`
- 🔔 زنگ اعلان‌های پنل (شمارندهٔ خوانده‌نشده، علامت‌گذاری خوانده‌شده، ناوبری مستقیم) + **نظرسنجی خودکار مانیفست گیت‌هاب** با اعلان خودکار «به‌روزرسانی جدید نسخهٔ X» برای مدیران — بدون باز کردن تب به‌روزرسانی
- Login مستقل + محافظت با Middleware و Layout

### 🎨 قالب‌ها و ظاهر (۳۰ قالب + ۵ صنف فروشگاه)
- 🖼 **۳۰ قالب صفحهٔ اصلی** (۲۵ قالب پایه + ۵ قالب پرچمدار صنف‌ها) با هدر/فوتر اختصاصی، پیش‌نمایش زنده با داده واقعی و اعمال یک‌کلیکی (بدون بیلد مجدد، بدون دستکاری داده)
- 🧭 **۵ سبک مگامنو** برای هر ۳۰ قالب: درختی دیجی‌کالایی / تصویری / آبشاری / زوم-محو / آبشاری+محصول ویژه
- 🔐 **صفحات ورود/ثبت‌نام مطابق قالب فعال** — ۶ سبک: سایبری / شیشه‌ای / لاکچری / روشن / مارکتی / فصلی
- 🧩 **محتوای اختصاصی هر قالب** (اسلاید / شوکیس / متن / لینک / برند) — قابل ویرایش از پنل؛ خالی بگذارید تا مقادیر سراسری استفاده شود
- 🕹 **قالب گیمینگ کد-تراش**: ریگ گیمینگ تمام-کد با فن‌های RGB روشن (بدون چرخش فن)، ماوس‌پد ARGB با نور لبه‌ای، هنر سه‌بعدی هدفون‌ها و آواتار کاربر در هدر
- 🛠 **حالت تعمیر**: تب اختصاصی در تنظیمات + ۴ کارت بزرگ با پیش‌نمایش زنده + ۴ قالب بازطراحی‌شده (تِک تاریک / مینیمال روشن / نئون شیشه‌ای / شمارش معکوس)
- 🌙 Dark/Light همهٔ قالب‌ها + ردزام هنری هر قالب + احترام کامل به prefers-reduced-motion

### امنیت
- Password hashing (bcrypt)، Session httpOnly، Rate Limiting روی APIهای حساس
- Zod روی همه ورودی‌ها، Prisma (ضد SQL Injection)، XSS-safe (بدون HTML خام در چت)
- آپلود امن: MIME + magic-bytes + حجم + تغییر نام تصادفی + بهینه‌سازی WebP
- Audit Log + جلوگیری از پرداخت تکراری (Idempotent verify) + مالکیت سفارش با تطبیق موبایل
- **هدرها در پروداکشن:** هدر `X-Frame-Options` به دلیل محیط Preview سندباکس عمداً در Next.js تنظیم نشده است. هنگام دیپلوی روی VPS، این هدر را در ریورس‌پروکسی (Caddy/Nginx) برای دامنه خودتان اضافه کنید:
  ```caddyfile
  # Caddy
  header X-Frame-Options "SAMEORIGIN"
  # یا دقیق‌تر: Content-Security-Policy "frame-ancestors 'self' https://your-domain.ir"
  ```

## 🚀 راه‌اندازی

### ⚡ نصب سریع با یک خط فرمان (پیشنهادی — v34 / app 29.0.0)

بستهٔ کامل پروژه **`Taj Electronics Main V13 VC.zip`** (برنامهٔ **از پیش ساخته‌شده** + سورس کامل + کاتالوگ نمونه + کانال به‌روزرسانی + همهٔ اسکریپت‌ها) را در **ریشهٔ سرور** آپلود کنید و فقط این یک خط را اجرا کنید:

```bash
sudo bash -c 'command -v unzip >/dev/null || (apt-get update -qq && apt-get install -y -qq unzip) 2>/dev/null || dnf install -y -q unzip; unzip -oq "Taj Electronics Main V13 VC.zip" && bash install.sh'
```

همین! این یک خط همه‌چیز را انجام می‌دهد: استخراج، نصب Node.js/Nginx/certbot در صورت نبود، **پرسیدن دامنه از شما**، استقرار برنامهٔ آماده در `/var/www/taj-electronics` (**بدون هیچ بیلدی روی سرور — حدود ۲ تا ۴ دقیقه، زیر ۱GB دیسک، بدون فشار روی RAM**)، تنظیم Nginx، صدور SSL رایگان (با دامنهٔ معتبر)، سرویس systemd با اجرای خودکار بعد از ری‌بوت و health-check روی `/api/health`:

> **آدرس نصب: `http://DOMAIN/install`** (یا `http://SERVER_IP/install`) — در مرورگر باز کنید و مدیر کل را بسازید.

- SHA-256 بستهٔ `Taj Electronics Main V13 VC.zip` برای راستی‌آزمایی: در تحویل هر نسخه اعلام می‌شود.
- اجرای مجدد `sudo bash install.sh` = ارتقای امن (داده‌ها، دیتابیس، آپلودها و `.env` حفظ می‌شوند).
- به‌روزرسانی‌های بعدی: `sudo bash /var/www/taj-electronics/update.sh` — حالت standalone بدون بیلد و در ~۱ دقیقه اعمال می‌شود. راهنما: [`UPDATE-GUIDE.md`](./UPDATE-GUIDE.md)
- مسیر Docker همچنان موجود است (`docker-compose.yml` + `Dockerfile`) — ولی دیگر لازم نیست و روی سرورهای کوچک توصیه نمی‌شود (بیلد سنگین: ~۱۰GB دیسک و ۳۰-۴۰ دقیقه).

> • **پیام‌های نوار متحرک قابل مدیریت:** کارت جدید «پیام‌های نوار متحرک (مارکی)» در تنظیمات ← فروشگاه — پیام‌های متحرک (مثل کد تخفیف WELCOME10) را **بنویسید، ویرایش کنید یا حذف کنید**؛ تا ۸ پیام با لینک اختیاری که همه در یک حلقهٔ بی‌نهایت می‌چرخند. لیست خالی = پیام اطلاع‌رسانی قبلی.
> • **پنل مدیریت کاملاً بازطراحی شد (طراحی فینوا):** نوار بالایی سفید با لوگوی گرادیانی، **ناوبری قرصی تیره** وسط صفحه (مثل داشبورد‌های SaaS حرفه‌ای)، پس‌زمینه روشن خاکستری، کارت‌های ۲۰px با نمودارهای کوچک واقعی (میله‌ای/خطی از داده‌های فروشگاه)، پنل تیره «آخرین سفارش‌ها» + پنل گرادیانی بنفش جزئیات سفارش با چیپ‌های شیشه‌ای، دکمه‌های ایندگو با سایه رنگی و منوی موبایل کامل. صفحه **ورود مدیران** هم با پنل گرادیانی متحرک و فرم حرفه‌ای بازطراحی شد.
> • **محصول ساده یا متغیر (قیمت ترکیبی):** در فرم محصول نوع محصول را انتخاب کنید — **ساده** فقط یک فیلد قیمت دارد؛ **متغیر** رنگ‌ها + مشخصه‌ها + **ماتریس قیمت ترکیبی (رنگ × مشخصه)** را باز می‌کند: هر ترکیب (مثلاً مشکی + ۸/۱۲۸ = ۲۰٬۹۰۰٬۰۰۰ و مشکی + ۱۲/۲۵۶ = ۲۳٬۹۰۰٬۰۰۰) **یک فیلد قیمت قطعی** دارد؛ موجودی هر ترکیب جدا است، ترکیب ناموجود غیرفعال می‌شود و سبد خرید قیمت همان ترکیب را نگه می‌دارد. تمام فیلدهای قیمت در پنل **سه‌رقم سه‌رقم جدا** می‌شوند (۲۰,۰۰۰,۰۰۰) و ارقام فارسی هم قبول است. راهنمای هوشمند جای‌گذاری مشخصات (رم → گیگابایت، سیستم‌عامل → Android/iOS و…) دیگر مقدار «اینچ» را برای همه نشان نمی‌دهد.
> • **دستیار هوشمند بدون موتور LLM هم مشاور واقعی است:** اگر موتور هوش مصنوعی روی سرور شما در دسترس نباشد (مثلاً پیکربندی موتور داخلی موجود نباشد)، دستیار **مشاورهٔ کامل قطعی** می‌دهد — قیمت، موجودی، مشخصات کلیدی، رنگ‌ها و جایگزین‌های واقعی همین دسته، همراه کارت محصول. فیلتر ارتباط هم سخت‌تر شد: برای «Galaxy S24 Ultra 512» فقط همان محصول پیشنهاد می‌شود (دیگر مدل‌های ضعیف‌تر همراهش نمی‌آیند).
> • **تحلیل خطاها در گزارش فعالیت مدیران:** دکمه «تست» تنظیمات هوش مصنوعی خطاها را **تحلیل‌شده و به زبان فارسی** نشان می‌دهد («سرور شما برای موتور داخلی مجاز نیست — .z-ai-config یافت نشد؛ Gemini را با کلید خودتان انتخاب کنید») و نتیجهٔ هر تست + خطاهای زمان اجرای چت با تحلیل کامل در «گزارش فعالیت مدیران» (نشان هوش مصنوعی) ثبت می‌شوند.
> • **قالب گیمینگ ۴D و فضانوردی:** بازطراحی کامل «گیمینگ و سایبر» — هیرو با **ردیاب حرکت ماوس سه‌بعدی** (crosshair + مختصات زنده + پارالاکس چندلایه)، بخش جدید «مانیتورهای گیمینگ ۴D» با رگ‌های واقع‌گرایانه مانیتور (قاب، پایه، حلقه RGB، گراف FPS، خیرگی که ماوس را دنبال می‌کند و تیلت سه‌بعدی)، کارت‌های لوداوت با براکت‌های گوشه، نوار KILL FEED پرفروش‌ها و چیدمان HUD — در حالت تاریک کل قالب (و حالا **همهٔ صفحات فروشگاه**) رگ ARGB می‌گیرد.
> • **قالب فعال در همهٔ صفحات:** تغییر قالب فروشگاه حالا هدر/فوتر اختصاصی همان قالب را در **صفحه محصول، لیست محصولات، سبد خرید، تسویه و همهٔ صفحات** اعمال می‌کند — نه فقط صفحه اصلی.
> • **رفع سرریز موبایل تسویه حساب:** شبکهٔ صفحه تسویه (و صفحات مشابه) در موبایل ۳۷۵px دیگر ۵۵px سرریز افقی ندارد — جاروب کامل همهٔ صفحات: صفر پیکسل.

> • **قیمت متفاوت برای هر رنگ یا مشخصه:** در فرم محصول می‌توانید برای **هر رنگ قیمت اختصاصی** (مثلاً رنگ خاص ۱۸٬۹۰۰٬۰۰۰) تعریف کنید و بخش جدید «گزینه‌ها و قیمت متغیر» مشخصه‌های متفاوت (ظرفیت/نسخه/رم…) با **اختلاف قیمت + یا −** و موجودی جداگانه می‌سازد. صفحه محصول قیمت را زنده با انتخاب کاربر نشان می‌دهد، گزینه‌های ناموجود غیرفعال‌اند و سبد خرید/تسویه حساب قیمت واقعی همان انتخاب را نگه می‌دارد (رفع باگ سریال‌سازی سبد که قیمت گزینه‌ها را نادیده می‌گرفت).

> • **هدر و فوتر جدید برای هر ۲۴ قالب غیرپیش‌فرض:** هر قالب صفحه اصلی حالا چیدمان کامل خودش را دارد — **هدر اختصاصی** (لوگو، جستجوی واقعی، ناوبری دسته‌بندی‌ها، حساب کاربری و سبد خرید با شمارنده زنده) در ۸ سبک متفاوت (نوار کلاسیک، پیل شناور شیشه‌ای، ماست‌هِد دوطبقه تحریریه‌ای، لبه-کناری، وسط‌چین، اپ‌مانند، بیلت تیکتی و مگا-فروشگاهی) و **فوتر اختصاصی** در ۸ چیدمان (مگا، وسط‌چین، مینیمال، باند تیره، تماس‌محور، ستون‌های درخشان، مجله‌ای با وردمارک غول‌پیکر و اپ‌مانند) — با ستون لینک‌های واقعی صفحات CMS، دسته‌بندی‌های زنده و **نوار برندهای عکس‌دار متحرک**. قالب پیش‌فرض (مدرن تِک) و صفحات داخلی (محصولات، سبد، تسویه و…) کاملاً دست‌نخورده باقی مانده‌اند — هدر/فوتر اختصاصی فقط در صفحه اصلی همان قالب فعال جایگزین می‌شود.
> • **پیش‌نمایش ادمین حالا همه‌چیز را نشان می‌دهد:** هر قالب در دیالوگ «ظاهر ← پیش‌نمایش» با **داده کامل واقعی** رندر می‌شود — اسلایدر (با پخش خودکار)، دسته‌بندی‌ها **با عکس**، محصولات ویژه/جدید/پرفروش/تخفیف‌دار، **محصولات انحصاری سه‌بعدی**، بنرهای شوکیس، استوری‌ها، برندهای عکس‌دار، پرسش‌های متداول و هدر/فوتر اختصاصی همان قالب — دیگر هیچ بخشی در هیچ قالبی خالی نیست (قبلاً ۲۲ قالب بخش «انحصاری» و برخی اسلایدر/دسته/برند نداشتند). عکس نمایشی هر دسته‌بندی/برند از پرفروش‌ترین محصولِ عکس‌دار همان دسته/برند ساخته می‌شود.

> • **رفع سرریز افقی موبایل در همه ۲۴ قالب:** گارد `overflow-x: clip` روی ریشه قالب‌ها + استک‌شدن کارت «پیشنهاد شگفت‌انگیز» تک‌هاب در موبایل — هیچ قالبی در عرض ۳۷۵px اسکرول افقی ندارد.

> • **۵ قالب جدید صفحه اصلی (مجموع ۲۵ قالب):** «نکسورا تک» (روشن و مدرن با هاله‌های بنفش و اکسنت لیمویی)، «تک‌هاب تاریک» (شبانه با درخشش نئونی، پیشنهاد ویژه با شمارش معکوس و نوار پیشرفت فروش)، «پرپل مال» (متراکم و پرانرژی با حلقه نئونی دور محصول و شماره‌های بزرگ پرفروش‌ها)، «نوا گلس» (شیشه‌ای لوکس با تیتر گرادیانی متالیک) و «نواترند کلین» (تمیز و ساده با حباب گرادیانی و کارت‌های شناور) — همه با استوری، محصولات، دسته‌بندی‌ها و برندهای **واقعی** فروشگاه پر می‌شوند و پیش‌نمایش داخل پنل ادمین برای **هر ۲۵ قالب** اکنون کار می‌کند (رفع مشکل پیش‌نمایش خالی قالب‌های v14.1). اعمال قالب مثل همیشه فقط چیدمان را عوض می‌کند — هیچ محصول یا داده‌ای تغییر یا حذف نمی‌شود.
> • **سیستم روش‌های ارسال:** ادمین از پنل (سفارش‌ها و پرداخت → روش‌های ارسال) هر روش ارسال دلخواه را می‌سازد/ویرایش می‌کند — **پست پیشتاز و سفارشی (پست ایران)، تیپاکس، چاپار اکسپرس، باربری برای کالای حجیم، پیک موتوری تهران/کرج، ارسال اکسپرس ۲۴ ساعته و تحویل حضوری** به‌صورت پیش‌فرض آماده‌اند؛ مشتری هنگام تسویه حساب روش را انتخاب می‌کند، هزینهٔ همان روش به مبلغ سفارش اضافه می‌شود و نام روش + زمان تقریبی تحویل روی سفارش ذخیره می‌شود (در پنل ادمین، صفحه سفارش مشتری و پیگیری سفارش دیده می‌شود). اگر روش فعالی تعریف نشود، ارسال مثل قبل از تنظیم ثابت فروشگاه محاسبه می‌شود.
> • **گفتگوی زنده + ارسال فایل در تیکت‌ها:** مشتری و ادمین در تیکت‌ها می‌توانند **تصویر و ویدیو** پیوست کنند (حداکثر ۴ فایل در هر پیام؛ تصویر تا ۵ و ویدیو تا ۶۴ مگابایت — با پیش‌نمایش، حذف و آپلود امن) و گفتگو **بدون رفرش صفحه به‌صورت زنده** به‌روز می‌شود (پیام جدید طرف مقابل ظرف چند ثانیه خودکار ظاهر می‌شود، نشان «گفتگوی زنده» و اسکرول خودکار به آخرین پیام).

## 🧙 نصب اولیه با جادوی نصب (Installer Wizard)

برای دیپلوی تازه (VPS / Docker / هاست)، **هیچ دستور ترمینالی لازم نیست**:

1. برنامه را بالا بیاورید (Docker یا اجرای مستقیم)
2. آدرس سایت را باز کنید — اگر نصب انجام نشده باشد، به‌صورت خودکار به `/install` هدایت می‌شوید
3. جادوی نصب ۶ گامی را دنبال کنید:
   - **خوش‌آمد** → شروع
   - **پیش‌نیازها** → بررسی خودکار محیط (Node، دیتابیس، دسترسی‌ها، وابستگی‌ها)
   - **دیتابیس** → تست اتصال + اجرای خودکار مایگریشن‌های Prisma (غیرمخرب)
   - **حساب مدیر** → نام کاربری (موبایل) / ایمیل / رمز عبور
   - **نصب نهایی** → ایجاد حساب، تنظیمات، ذخیره‌سازی، قفل نصب (هر مرحله یک عملیات واقعی)
   - **پایان** → دکمه‌های «ورود به پنل مدیریت» و «مشاهده فروشگاه»
4. با همان حساب به `/admin` وارد شوید و تنظیمات درگاه پرداخت / AI را از «تنظیمات» انجام دهید

> 💡 پس از نصب، هر دامنه‌ای که برنامه روی آن اجرا شود به‌صورت خودکار تشخیص داده می‌شود — نیازی به وارد کردن دامنه نیست.

### امنیت نصب

- بعد از تکمیل نصب، سطر `InstallationState` در دیتابیس با `installed=true` قفل می‌شود:
  - `/install` برای همیشه به `/` ریدایرکت می‌شود (و APIهای آن کد 403 می‌دهند) — نصب مجدد ممکن نیست
  - صفحه `/install` و همه endpointهای `/api/install/*` روی سرور قفل می‌شوند (فقط مخفی‌سازی UI نیست)
- نصب **غیرمخرب** است: مایگریشن‌ها بدون `--accept-data-loss` اجرا می‌شوند؛ اگر دیتابیس موجودی ناسازگار باشد، متوقف و اعلام می‌شود (هیچ داده‌ای حذف نمی‌شود)
- رمز مدیر با bcrypt هش می‌شود؛ در پاسخ‌های API هرگز رمز یا کلیدی برگردانده نمی‌شود
- همه endpointهای نصب Rate-Limit + اعتبارسنجی Zod دارند و خطاهای فنی/stack trace به کاربر نمایش داده نمی‌شوند
- دیپلوی‌های قدیمی (قبل از Installer) به‌صورت خودکار شناسایی و «نصب‌شده» فرض می‌شوند
- ⚠️ مثل وردپرس: در فاصله بین دیپلوی و تکمیل نصب، `/install` برای همه باز است — بلافاصله پس از دیپلوی نصب را کامل کنید

### نصب دستی (جایگزین CLI)

اگر ترجیح می‌دهید بدون مرورگر نصب کنید، همان مراحل با دستورات:

```bash
bun run db:push        # جداول
bun scripts/seed.ts    # ادمین + داده نمونه (اختیاری)
```

### 🔒 تغییر اطلاعات ورود مدیر (ایمیل / موبایل / رمز)

**روش ۱ — از خود پنل (پیشنهادی):**
`/admin/account` (منوی «حساب من» در نوار کناری یا منوی کاربر بالا):

### 🔑 بازیابی رمز عبور (فراموشی رمز) — با ایمیل واقعی SMTP

**تنظیم SMTP (بدون دست کد زدن):** `پنل مدیریت → تنظیمات → ایمیل و SMTP`
- Host / Port / نوع امنیت (STARTTLS برای پورت ۵۸۷ — SSL/TLS برای پورت ۴۶۵) / نام کاربری / رمز / نام و ایمیل فرستنده / Reply-To
- **تست اتصال SMTP** (اتصال و احراز هویت واقعی) و **ارسال ایمیل آزمایشی** از همان تب
- رمز عبور SMTP **در دیتابیس به‌صورت AES-256-GCM رمزنگاری‌شده** ذخیره می‌شود (کلید از `AUTH_SECRET` مشتق می‌شود) و **هرگز به مرورگر برگردانده نمی‌شود** — هنگام ویرایش فقط مقدار جدید وارد می‌شود
- مثال Gmail: `smtp.gmail.com` + پورت ۵۸۷ (STARTTLS) یا ۴۶۵ (SSL/TLS) — با فعال بودن 2FA معمولاً باید **App Password** ساخت (از myaccount.google.com → Security → App passwords)، رمز معمولی گوگل کار نمی‌کند

**رفتار سیستم بازیابی (production):**
- کاربر ایمیل یا موبایل را در `/forgot-password` وارد می‌کند → پاسخ همیشه عمومی است («اگر حسابی با این اطلاعات وجود داشته باشد…») — بدون افشای وجود/نبود حساب
- توکن با `crypto.randomBytes` ساخته می‌شود، فقط **هش SHA-256 آن** در دیتابیس ذخیره می‌شود (توکن خام فقط داخل لینک ایمیل است)، ۴۵ دقیقه اعتبار، **یک‌بارمصرف**، درخواست جدید توکن قبلی را باطل می‌کند
- لینک از دامنه واقعی درخواست/کانفیگ ساخته می‌شود (`NEXT_PUBLIC_SITE_URL` یا هدرهای پروکسی) — هیچ دامنه‌ای در کد هاردکد نیست
- بعد از تغییر رمز: همه نشست‌های کاربر خاتمه می‌یابند + اعلان امنیتی + ثبت در Audit Log (برای اکانت‌های مدیریتی)
- اگر SMTP خاموش/ناقص باشد: پیام عمومی «امکان ارسال ایمیل بازیابی در حال حاضر وجود ندارد…» — **بدون نمایش لینک/توکن در مرورگر و بدون هیچ رفتار دموی آزمایشی**
- Rate limit: ۵ درخواست در ۱۰ دقیقه برای هر IP + ۳ درخواست در ساعت برای هر شناسه؛ صفحه `/reset-password` هم ۱۰ تلاش در ۱۵ دقیقه

> ⚠️ اگر `AUTH_SECRET` را بعد از ذخیره رمز SMTP تغییر دهید، رمز رمزگشایی نمی‌شود (به‌عنوان رمز نادرست تلقی می‌شود) — کافی است رمز SMTP را از پنل دوباره ذخیره کنید.
